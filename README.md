# fer_tools

fer tools contains scripts for dataset aggregation, model training and testing, and embedding generation of the different Facial Expression Recognition datasets.

The architecture currently being used for this implementation is miniXception by oarriaga.   

The root folder contains the scripts for:
1. Splitting datasets
2. Training miniXception models
3. Inferencing using the trained models.

Notes: 


Other folder contents:
(models) 
Directory for storing and loading the different trained models. 

Notes:The default files included here were trained using a local machine, the specs of which will be updated later. (todo)


(vis)
Included here are the scripts for data analysis. These are:
1. Confusion Matrix generating files
2. Embedding generation
3. F1 scores computation

Notes: The files here can be accessed Jupyter Notebook. Default
